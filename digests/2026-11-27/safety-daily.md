# Daily Digest (2026-11-27)

## Top 3 Developments

**Think Tank Calls for New US Federal Institutions to Oversee Frontier AI Capability Growth** - [IAPS's six-memo "Securing the Frontier" series](https://www.iaps.ai/research/scaling-securely-recommendations-for-the-executive-branch) argues that frontier labs are now using unreleased internal models to accelerate their own R&D faster than external oversight can track, and calls on the US executive branch to build new institutions capable of matching that pace, covering [capability security](https://www.iaps.ai/research/advancing-ai-capabilities-call-for-urgent-action-to-secure-the-frontier), [high-risk development oversight](https://www.iaps.ai/research/ensure-oversight-of-high-risk-ai-development), [deployment control](https://www.iaps.ai/research/secure-and-control-high-risk-ai-deployment), [US leadership](https://www.iaps.ai/research/preserve-us-leadership-in-frontier-ai), [resilience against AI-enabled threats](https://www.iaps.ai/research/build-resilience-against-ai-enabled-threats), and [monitoring China's frontier risks](https://www.iaps.ai/research/monitor-and-manage-chinas-frontier-ai-risks). This matters because it is a coordinated, Tier-1 policy push explicitly framing internal-model-driven R&D acceleration as a governance blind spot requiring urgent institutional response, timed to shape executive-branch strategy.

**Rowhammer Attack Implants Backdoors Below the Software Stack via Shared GPU Memory** - [BridgeHammer](https://arxiv.org/abs/2611.34684v1) demonstrates a hardware-level Rowhammer exploit against CPU-iGPU shared memory in heterogeneous SoCs that implants targeted misclassification backdoors into deployed models without any software access. This matters because it extends the hardware-attack theme seen in last week's EM fault-injection work ([FATCAT](https://arxiv.org/abs/2611.31129v1)) into persistent model tampering, a threat class current model-integrity auditing pipelines cannot detect.

**Diffusion-Based Adversarial Defenses Found Mismatched to Real Agentic Inputs** - [Agentic-Level Adversarial Purification](https://arxiv.org/abs/2611.34181v1) shows that diffusion purifiers widely used to defend vision-language agents were validated at fixed resolutions inconsistent with the native-resolution, multi-element pages agents actually process in deployment. This matters because it reveals that a standard defensive layer for web-browsing VLM agents has an unevaluated gap exactly where single-image hijacks are most likely to occur.
