# Research Papers (2026-08-21)

## Key Papers

**[Inadvertent Context Leakage in Language Models](https://arxiv.org/abs/2608.19857v1)** demonstrates that sensitive information in an LLM's context window creates hidden correlations in benign outputs, allowing reconstruction even when the model refuses direct extraction. The authors show that adversaries can engineer prompts to amplify this effect, using the model as a covert channel for information exfiltration. This reveals a fundamental privacy vulnerability in AI agents handling sensitive user data like calendars, credentials, and health records.

**[ConceptGuard: Benchmarking Context-Sensitive Unlearning in Large Language Models](https://arxiv.org/abs/2608.20338v1)** introduces a benchmark that evaluates whether LLMs can selectively remove harmful knowledge while preserving beneficial uses of the same concepts. Unlike existing evaluations that use disjoint forget/retain sets, this work tests context-dependent unlearning—crucial for real-world deployment where concepts like "explosives" should be forgotten in bomb-making contexts but retained for chemistry education. This addresses a critical gap in machine unlearning evaluation methodology.

**[COPA: Continual Preference Optimization for Adaptive Prompt Injection Defense](https://arxiv.org/abs/2608.19982v1)** presents a dynamic defense mechanism that continuously adapts to evolving prompt injection attacks through iterative preference optimization. Rather than relying on static defenses that become obsolete as attacks evolve, COPA uses lifelong learning to maintain robustness against adaptive adversaries who modify their strategies over time. This represents an important shift toward adaptive security measures that can keep pace with evolving attack vectors.

**[EchoCoT: Extracting Hidden Chain-of-Thought from Large Reasoning Models](https://arxiv.org/abs/2608.20055v1)** reveals that proprietary LLMs' valuable internal reasoning traces can be extracted through API interactions via a "reasoning replay" vulnerability between tool calls. The authors develop a multi-step attack that recovers hidden chain-of-thought traces near-verbatim from black-box models. This exposes significant intellectual property risks for model developers and highlights security vulnerabilities in API design for reasoning models.

**[AI4AI-Bench: Benchmarking LLM Agents in Algorithmic Design for Recursive Self-Improvement](https://arxiv.org/abs/2608.20318v1)** creates the first benchmark specifically testing whether AI agents can design training algorithms—a key capability for recursive self-improvement scenarios. The benchmark isolates algorithmic design ability from other factors and evaluates whether agents can improve the process that produces future AI systems. This directly addresses critical questions about AI systems' potential for autonomous capability enhancement and long-term safety implications.

**[Understanding as an Explicit and Assessable Component of Frontier AI Safety Decisions](https://arxiv.org/abs/2608.19816v1)** proposes a methodology for making AI system understanding explicit and assessable in high-stakes deployment decisions. As AI-generated safety cases become common, the authors argue that the existence of documentation no longer guarantees sufficient human understanding for responsible decision-making. Their framework requires explicit description of four key objects to ensure decision-makers have adequate comprehension of system capabilities and risks.

**[MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use](https://arxiv.org/abs/2608.20202v1)** identifies how faithfully retrieved memories can distort LLM reasoning even when the memories are accurate and relevant. The benchmark reveals "memory-induced cognitive traps" where models become overconfident, exhibit confirmation bias, or suffer from anchoring effects based on retrieved information. This is crucial for AI safety as memory-augmented systems become more prevalent in decision-making contexts.

**[PolicyGuide: From Guarding One Action to Guiding the Whole Workflow for Policy-Compliant LLM Agents](https://arxiv.org/abs/2608.19861v1)** addresses the limitation of action-level safety checks by introducing workflow-level policy compliance for customer service agents. While runtime safeguards can block individual risky actions, they don't guide agents through complex multi-step procedures that require policy adherence throughout the entire workflow. This work bridges the gap between point-in-time safety checks and comprehensive policy compliance across extended interactions.
