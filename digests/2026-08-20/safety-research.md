# Research Papers (2026-08-20)

## Key Papers

**[Beyond the Transcript: Detecting Covert Co ordination in Latent Multi-Agent Communication](https://arxiv.org/abs/2608.19161v1)** introduces Verifiable Latent Alignments (VLA), a framework for monitoring hidden communication channels between language model agents that could enable harmful coordination. The system links private latent states to public actions using shared identifiers, enabling detection of covert coordination patterns. This addresses a critical AI safety concern as multi-agent systems become more prevalent in high-stakes applications.

**[When Safety Overrides Vision: Exploring Dynamics between Vision Influence and Safety Alignment in Vision-Language Models](https://arxiv.org/abs/2608.18628v1)** reveals that safety-aligned vision-language models frequently refuse to answer questions they can actually solve when given safety-constrained instructions, even with identical inputs. The research shows this occurs because safety alignment can suppress visual grounding capabilities rather than just filtering outputs. This finding has important implications for deploying VLMs in safety-critical applications where both accuracy and appropriate caution are essential.

**[Breaking the weakest link to evade vision language models](https://arxiv.org/abs/2608.18938v1)** demonstrates vulnerabilities in Vision Language Models through adversarial perturbations that exploit the multimodal alignment process. The authors show how attackers can manipulate visual inputs to cause misalignment between vision and language components, leading to evasion of safety measures. This research highlights critical security gaps in VLM deployment that need addressing before widespread adoption in sensitive applications.

**[Catastrophic Learning: A New Attack Vector on Continual Learning Networks](https://arxiv.org/abs/2608.18976v1)** identifies a novel security vulnerability in continual learning systems where adversaries can manipulate training data to reduce the model's ability to learn new tasks (attacking plasticity) rather than just causing forgetting. These "learning blockers" are particularly dangerous because they can persistently degrade future learning capabilities. This represents a fundamental threat to adaptive AI systems that must continuously update their knowledge.

**[Mixture-of-Expert Blocks Contain Strong Hallucination Detection Signals](https://arxiv.org/abs/2608.17687v1)** discovers that Mixture-of-Experts architectures naturally provide token-level signals for detecting hallucinations through their expert routing patterns. The research shows that expert activation patterns can reliably identify when models generate false content at the individual token level. This finding offers a promising path toward real-time hallucination detection without requiring external verification systems.

**[Judge, Retrieve, or Abstain: Uncertainty-Guarded LLM Judging with Provable Risk Guarantees](https://arxiv.org/abs/2608.17994v1)** addresses the reliability challenges of using LLMs as judges for objective tasks by introducing a framework with mathematical risk guarantees. The system can decide whether to judge directly, retrieve additional information, or abstain from judgment based on uncertainty estimates. This provides a principled approach to LLM evaluation that balances automation with reliability in high-stakes assessment scenarios.

**[Detecting Backdoors in Object Detection via Pre-NMS Prediction Distribution Shift](https://arxiv.org/abs/2608.19088v1)** presents DistScan, a method for detecting backdoor attacks in object detection models by analyzing prediction distributions before non-maximum suppression. The approach successfully identifies scene-level attacks where triggers affect all objects simultaneously, addressing a gap in existing detection methods. This is crucial for securing computer vision systems deployed in safety-critical applications like autonomous vehicles.

**[SPK: Eliciting Structured Prior Knowledge for Interpretable Out-of-Distribution Detection in Real-Time Object Detection](https://arxiv.org/abs/2608.19080v1)** introduces a framework that makes implicit knowledge in object detectors explicit for better out-of-distribution detection. By structuring and interpreting the latent priors encoded in detector representations, the system can identify when objects fall outside the training distribution. This enhances the reliability and interpretability of object detection in real-world deployment scenarios.
