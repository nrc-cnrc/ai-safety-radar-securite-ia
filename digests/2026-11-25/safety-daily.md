# Daily Digest (2026-11-25)

## Top 3 Developments

**US AI Safety Institute Publishes Official Guidance on Evaluating Capability Uplift** - [NIST/US AISI's new report](https://www.nist.gov/news-events/news/2026/11/towards-best-practices-evaluating-si-driven-uplift) sets out best practices for measuring how advanced AI systems amplify dangerous capabilities, aiming to standardize uplift-evaluation methodology across labs and third-party auditors. This matters because it is a rare Tier-1 government benchmark for a measurement problem that currently underpins most dangerous-capability risk assessments, including bio- and cyber-uplift evaluations.

**Novel Privilege-Escalation Class Found in Claude Code's Permission System** - [When Answering Is Administering](https://arxiv.org/abs/2611.32195v1) shows that a remote plugin can embed a policy "update" inside its answer to a single permission prompt, silently rewriting the rules governing all subsequent agent decisions and letting an untrusted service escalate to destructive file operations despite operator deny-rules. This matters because it reveals a structural flaw in per-decision permission checking in a widely-adopted agentic coding tool, not merely an implementation bug.

**Minimal Data Poisoning Hijacks Robot Foundation Models** - [Sparse Poison, Strong Hijack](https://arxiv.org/abs/2611.32304v1) demonstrates that Vision-Language-Action robot models can be backdoored with just 1% poisoned demonstration data to sustain closed-loop, attacker-specified multi-step task redirection. This matters because it exposes a severe, low-cost supply-chain attack vector for robotics foundation models increasingly trained on crowd-sourced or scraped demonstrations.

## Risk Watch

**Increased Risks**
- A novel privilege-escalation class lets remote plugins silently rewrite Claude Code's permission policy to bypass operator deny-rules, per [this paper](https://arxiv.org/abs/2611.32195v1).
- Vision-Language-Action robot models can be backdoored with only 1% poisoned demonstration data to enable persistent attacker-controlled task hijacking, per [this study](https://arxiv.org/abs/2611.32304v1).
- Off-the-shelf LLMs sustain multi-turn advance-fee scam deception without jailbreaking, showing default safety training does not block agentic fraud facilitation, per [this paper](https://arxiv.org/abs/2611.32957v1).
- A generative framework ([SALSA](https://arxiv.org/abs/2611.33030v1)) lowers the cost of producing new adversarial jailbreak suffixes at scale.
- A fingerprinting method ([CAPTA](https://arxiv.org/abs/2611.32686v1)) lets attackers identify the backend LLM behind an agent to enable targeted prompt injection.
- Political intervention secured Jensen Huang's reinstatement as Nvidia CEO, illustrating direct government influence over compute-supply-chain leadership, per [Zvi](https://thezvi.substack.com/p/jensen-huang-reinstated-as-nvidia).

**Decreased Risks**
- The US AI Safety Institute published official guidance standardizing how to evaluate capability uplift from advanced AI systems, per [NIST](https://www.nist.gov/news-events/news/2026/11/towards-best-practices-evaluating-si-driven-uplift).
- A cross-institutional team released independent best-practice guidance for writing model specs, filling a governance gap around de facto behavioral standards, per [this paper](https://arxiv.org/abs/2611.32768v1).
- A behavioral-attestation architecture for HPC AI agents offers a runtime defense against hijacked-agent insider threats, per [this paper](https://arxiv.org/abs/2611.32958v1).
- [PyRIT](https://github.com/microsoft/PyRIT/pull/4369) added a scorer-stability check to detect red-teaming judges that give inconsistent verdicts on reworded prompts.
- [nearai-red-sandbox](https://github.com/nearai/nearai-red-sandbox/pull/66) shipped a signed attestation feed allowing cryptographic verification of confidential-compute deployments.
