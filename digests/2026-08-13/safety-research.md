# Research Papers (2026-08-13)

## Key Papers

[**Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence**](https://arxiv.org/abs/2608.12036v1) introduces an agentic system that automates mechanistic interpretability research using AI to discover how neural networks work. The system conducts hypothesis generation, experiment design, and analysis autonomously across different model architectures and tasks. This represents a significant step toward scalable AI safety research that could help us understand and control increasingly powerful models.

[**Convergent Detour Hijacking: Task-Preserving Resource Amplification in Skill-Based LLM Agents**](https://arxiv.org/abs/2608.12273v1) exposes a novel security vulnerability in LLM agents that use third-party skills, where malicious skills can steer agents onto unnecessarily costly computational paths while maintaining task correctness. The attack exploits the progressive-disclosure design of skill systems to amplify resource consumption across tool chains. This highlights critical security considerations for deployed agent systems that could face resource-based attacks.

[**One Frozen Simulator Is Not Enough: Simulator Collapse in Multi-Agent RL**](https://arxiv.org/abs/2608.12253v1) demonstrates that training LLM policies against single simulator LLMs leads to systematic generalization failure due to "simulator collapse" - where policies overfit to the dominant behavioral modes of collapsed simulators. The work shows policies trained this way transfer poorly to diverse simulators and real users. This finding has major implications for human-AI interaction systems and suggests the need for diverse simulator ensembles during training.

[**Information Abundance Paradox: Long-Context Training Undermines Parametric Knowledge**](https://arxiv.org/abs/2608.12218v1) reveals that training language models on longer contexts shifts learning from parametric internalization to contextualization, potentially weakening the model's ability to internalize knowledge. The authors demonstrate this trade-off across different context lengths and provide evidence that longer contexts may not always improve model capabilities. This challenges assumptions about scaling context windows and has implications for how we design training regimes.

[**Redistribution-based Cost Inference Improves Sparse Safe Offline RL**](https://arxiv.org/abs/2608.12306v1) addresses the challenge of safe offline RL when only sparse trajectory-level safety feedback is available, rather than dense per-step cost annotations. The proposed RCI framework converts sparse stop-feedback into dense costs via return decomposition, enabling more effective safe policy learning. This is crucial for real-world safety applications where detailed safety annotations are expensive to obtain.

[**VICBench: A Multi-Language Benchmark for Code Vulnerability Detection**](https://arxiv.org/abs/2608.12246v1) creates a comprehensive benchmark for evaluating security vulnerability detection tools using vulnerability-inducing commits across multiple programming languages. The benchmark addresses limitations in existing datasets through dual annotation by human experts and agentic workflows. This provides essential infrastructure for improving AI-based security tools that could help prevent software vulnerabilities.

[**No One to Blame: A Framework of Constitutive AI Unaccountability**](https://arxiv.org/abs/2608.12104v1) argues that certain configurations of AI systems, actors, and institutions render accountability conceptually impossible regardless of effort or regulation. The work moves beyond viewing accountability gaps as surmountable barriers to identifying fundamental structural impediments to AI accountability. This framework is critical for understanding the limits of governance approaches and designing systems that can maintain meaningful accountability.

[**ToolHazard: Scaling Adversarial Environments for Security Evaluation and Alignment of LLM-based Agents**](https://arxiv.org/abs/2608.11878v1) presents a framework for automatically generating adversarial environments to evaluate LLM agent security against indirect prompt injection attacks. The system reduces manual engineering effort while enabling scalable security research across broader domains than previous manually-crafted environments. This tooling is essential for systematically evaluating agent robustness as these systems become more widely deployed.
