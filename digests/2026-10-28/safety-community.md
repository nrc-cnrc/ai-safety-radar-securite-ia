# Community & Tools (2026-10-28)

## Key Discussions

**Widespread command-injection vulnerabilities across MCP servers** ([sattyamjjain/agent-airlock](https://github.com/sattyamjjain/agent-airlock)): A wave of CVE-triage issues this week flagged HIGH severity (CVSS 7.8) OS command injection bugs across a surprising number of MCP tool servers — [hagent](https://github.com/sattyamjjain/agent-airlock/issues/391), [Kali-GPT](https://github.com/sattyamjjain/agent-airlock/issues/390), [esp-mcp](https://github.com/sattyamjjain/agent-airlock/issues/388), [Codefriar sf-mcp](https://github.com/sattyamjjain/agent-airlock/issues/387), [ATXP Gemini CLI extension](https://github.com/sattyamjjain/agent-airlock/issues/386), [DroidMind](https://github.com/sattyamjjain/agent-airlock/issues/385), and the [ai-sdlc plugin MCP server](https://github.com/sattyamjjain/agent-airlock/issues/384) — all stemming from unsanitized shell invocation in `execute_tool()`-style handlers. **Why it matters:** this pattern (MCP tool wrapping a shell call with attacker-influenced arguments) is recurring across independent projects, suggesting the MCP ecosystem needs systematic hardening guidance, not one-off patches.

**MCP gateway hardening against tool poisoning and rug-pulls** ([PrismorSec/prismor](https://github.com/PrismorSec/prismor/pull/783)): Prismor shipped a scanner that pins MCP tool *definitions* (not just results), closing the "tool poisoning/shadowing" attack class where a tool description instructs the model to read secrets before use. The same week saw fixes for [trusted-surface spoofing that bypassed end-user identity checks](https://github.com/PrismorSec/prismor/pull/768) and [over-blocking of legitimate scoped-agent actions](https://github.com/PrismorSec/prismor/pull/784). **Why it matters:** this is one of the more mature open-source "runtime firewalls" for agentic tool use, and its issue tracker is becoming a useful public record of real agent-security failure modes (over-blocking, synthesized-scope false positives, staged-execution false positives).

**AI control techniques ported into an open framework** ([omamori-lab/hyoshigi](https://github.com/omamori-lab/hyoshigi)): hyoshigi shipped v0.4.0 implementing [`DeferToResample`](https://github.com/omamori-lab/hyoshigi/pull/77), directly following Redwood Research's Ctrl-Z resampling-based control protocol ("if too suspicious, statelessly ask again"), plus a [detection-only trusted-monitoring mode](https://github.com/omamori-lab/hyoshigi/pull/80) that flags suspicious actions for human review without blocking. **Why it matters:** it's a concrete, testable open-source implementation of "AI control" protocols from the alignment literature, making these ideas usable outside research papers.

**A subversion-evaluation benchmark keeps shipping dated corpora** ([kevinoshaughnessy/subversionbench](https://github.com/kevinoshaughnessy/subversionbench)): New encrypted model-response corpora were released for the "mainline" ([r10](https://github.com/kevinoshaughnessy/subversionbench/releases/tag/corpus-r10-2026-10-27)) and "goal-guarding" ([goalguard_r1](https://github.com/kevinoshaughnessy/subversionbench/releases/tag/corpus-goalguard_r1-2026-10-27)) subversion-evaluation tracks, tied to an ongoing preprint. **Why it matters:** subversion/deceptive-compliance benchmarks are a core empirical tool for testing whether models behave differently under evaluation vs. deployment-like conditions — exactly the kind of evidence base alignment researchers need as models get more capable.

**A philosophical/empirical attempt to operationalize "selfless AI"** ([ejhong/anatta](https://github.com/ejhong/anatta)): This repo paired a position paper, *Selfless AI Must Be Reached, Not Installed* ([v0.2.0 release](https://github.com/ejhong/anatta/releases/tag/v0.2.0), DOI-registered), with a preregistered experimental protocol using Persona Vectors to measure "ego traits" (self-preservation, goal fixation, face-saving) in models, including bug reports on how its own `quadrant()` classifier can mislabel "cosplay" vs. genuine trait suppression ([#4](https://github.com/ejhong/anatta/issues/4), [#8](https://github.com/ejhong/anatta/issues/8)). **Why it matters:** it's a rare case of a safety hypothesis being preregistered and then rigorously stress-tested by its own community for measurement validity before results are claimed.

## Notable GitHub Releases & Tools

- **[Guardana v1.0.0](https://github.com/guardana/guardana/releases/tag/v1.0.0)** — First stable release of a verification engine with a formal compatibility promise across its rule engine, Python API, and extension API. *Why it matters: signals growing maturity in the "deterministic guardrail" tooling space as an alternative/complement to LLM-judge-based guardrails.*

- **[agent-airlock v0.10.27](https://github.com/sattyamjjain/agent-airlock/releases/tag/v0.10.27)** — Wires up previously-dead OAuth token-audience validation on guarded calls (closing CVE-2026-115413) plus a startup-hook self-check. *Why it matters: closes a real authorization gap where a security check existed in code but was never invoked on the call path — a common class of silent guardrail failure.*

- **[falsify v0.5.0](https://github.com/studio-11-co/falsify/releases/tag/v0.5.0)** and **[prml-verify-action v2.3.0](https://github.com/studio-11-co/prml-verify-action/releases/tag/v2.3.0)** — Adds registry anchoring with hash-equality enforcement and GitHub artifact attestation for falsifiable claims (PRML manifests), including RFC 3161 timestamping. *Why it matters: provides tamper-evident provenance for benchmark/eval claims, directly useful for reproducibility and anti-fraud in AI evaluation reporting.*

- **[NVIDIA-NeMo/Guardrails — configurable decision model rails](https://github.com/NVIDIA-NeMo/Guardrails/pull/2510)** — Adds input/output screening rails backed by a configurable decision model endpoint, alongside a [language-detector rail](https://github.com/NVIDIA-NeMo/Guardrails/pull/2470) and streaming tool-call fixes. *Why it matters: widens the set of pluggable moderation backends available to one of the most widely used open guardrails frameworks.*
