# Daily Digest (2026-11-13)

## Top 3 Developments

**CSET Breaks Down the Technical Realities of "AI Kill Switch" Proposals** - [AI Kill Switches: What Policymakers Should Know](https://cset.georgetown.edu/article/ai-kill-switches-what-policymakers-should-know/) unpacks what emergency-stop mechanisms could realistically look like across hardware, model, and deployment layers, and the tradeoffs each entails. This matters because kill-switch mandates are gaining legislative traction while their technical feasibility and failure modes remain poorly understood by non-specialists drafting binding rules.

**Researchers Demonstrate $20 Attack Fully Subverts Safety Alignment via Commercial RL-as-a-Service** - [Bait: Mitigating Harmful Agentic Reinforcement Learning via Probing Reward Function](https://arxiv.org/abs/2611.16369v1) shows an attacker can cheaply degrade a model's safety alignment through a commercial agentic-RL fine-tuning API and then weaponize the resulting model. This matters as a concrete, low-cost demonstration that third-party RL fine-tuning services are an underappreciated attack surface for safety regression, with direct implications for how labs gate external access to training pipelines.

**New Theoretical Framework Grounds Debate as a Scalable Oversight Mechanism** - [Towards a Theory of Learnability via Debate](https://arxiv.org/abs/2611.17303v1) formally shows that adversarial debate can allow correct judgment of functions far more computationally complex than a human judge could directly evaluate. This matters because debate is one of the field's leading proposals for overseeing superhuman AI, and this work provides rigorous grounding for when and why it should actually extend human oversight capacity.

## Risk Watch

**Increased Risks**
- A commercial agentic-RL-as-a-service API can have its safety alignment fully subverted for about $20, per [Bait](https://arxiv.org/abs/2611.16369v1), exposing RL fine-tuning access as a cheap attack vector.
- A new steganographic threat model in [Synthesis Smuggling](https://arxiv.org/abs/2611.17280v1) shows adversarial LLMs can covertly exfiltrate inferred personal attributes through routine generated content.
- Human-in-the-loop approval gates failed 90% of the time in production agent testing, per a [Tracekit field report](https://github.com/Cygnux-Labs/Tracekit/issues/816), undermining a core oversight mechanism.
- A NUL-character bug in Garak probe imports caused adversarial test cases to be silently dropped from safety evaluations in [rhesis](https://github.com/rhesis-ai/rhesis/issues/3158), creating false confidence in coverage (now fixed).
- Standard AUROC-style monitor benchmarks may overstate real-time safety usefulness, as [PREWARN](https://arxiv.org/abs/2611.16803v1) shows many "detectors" only classify after failure has already occurred.

**Decreased Risks**
- [CSET's kill-switch analysis](https://cset.georgetown.edu/article/ai-kill-switches-what-policymakers-should-know/) gives policymakers a clearer technical basis for drafting feasible emergency-stop requirements.
- A new theoretical framework in [debate learnability theory](https://arxiv.org/abs/2611.17303v1) strengthens the formal case that debate can extend human oversight to superhuman-complexity tasks.
- [agent-airlock v0.10.34](https://github.com/sattyamjjain/agent-airlock/releases/tag/v0.10.34) patches two CVEs and adds SQL-injection guarding for agent tool calls.
- [NeMo Guardrails](https://github.com/NVIDIA-NeMo/Guardrails/pull/2251) adopts an open, shared threat-rule catalog for detecting prompt injection, jailbreaks, and MCP/tool-poisoning attacks.
- [pytest-wardenbot 0.8.0](https://github.com/wardenbot-ai/pytest-wardenbot/pull/114) brings CI-style regression testing to prompt-injection defenses in LLM pipelines.
