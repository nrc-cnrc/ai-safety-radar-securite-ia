# Community & Tools (2026-11-15)

## Key Discussions

**1. Aider's architect mode auto-applies edits without confirmation** — A [static-review issue](https://github.com/Aider-AI/aider/issues/5748) found that `--auto-accept-architect` defaults to `True` in the CLI, meaning architect-mode edits from the LLM are applied to a user's codebase without a human confirmation gate. This sits alongside two other aider security PRs merged this week: [scrubbing API keys from logged command lines](https://github.com/Aider-AI/aider/pull/5986) and [stripping ANSI/control characters from shell-command confirmation prompts](https://github.com/Aider-AI/aider/pull/5981) (which could otherwise let a model-proposed command visually spoof the confirmation text). *Why it matters: these are concrete instances of the "confirm-before-acting" safety property quietly failing by default in a widely-used coding agent — exactly the kind of UX default that erodes human-in-the-loop guarantees at scale.*

**2. SSRF guard bypasses in agent-to-agent file fetch (agboss)** — A cluster of security issues in the [agboss](https://github.com/agbossjs/agboss) multi-agent orchestration framework shows an SSRF guard being bypassed through an environment proxy ([#916](https://github.com/agbossjs/agboss/issues/916)), through connection pooling on a refused request ([#1138](https://github.com/agbossjs/agboss/issues/1138)), and spans reporting "OK" for requests that actually failed after a 2xx ([#1139](https://github.com/agbossjs/agboss/issues/1139)). Fixes landed same-day in [PR #1164](https://github.com/agbossjs/agboss/pull/1164). *Why it matters: SSRF in agent-to-agent file transport is a classic agentic-AI attack surface — these findings show how many subtle bypass vectors (proxies, keep-alive, redirects) a "guard" needs to close to actually hold.*

**3. Path traversal and scoring-order bugs in EleutherAI's lm-evaluation-harness** — A [security fix](https://github.com/EleutherAI/lm-evaluation-harness/pull/4540) closes a YAML `include:` directive that previously accepted arbitrary absolute paths and path traversal, letting task configs pull YAML from anywhere on disk. A companion [IFEval fix](https://github.com/EleutherAI/lm-evaluation-harness/pull/4616) addresses non-deterministic scoring caused by unseeded random draws inside vendored checkers. *Why it matters: lm-eval-harness underlies countless published safety/capability benchmark numbers — both file-system integrity and score determinism bugs directly threaten the reproducibility of eval-based safety claims.*

**4. HELM finds ~10% of MedMCQA questions unscoreable against disputed answer keys** — A new [HELM PR](https://github.com/stanford-crfm/helm/pull/4383) introduces a "verified-keys" track after auditing the first 6,800 MedMCQA questions and finding roughly 1 in 10 cannot be cleanly scored — keys are disputed, questions are defective, or the "true" answer isn't among the options. *Why it matters: this is a reminder that widely-cited medical-LLM leaderboard numbers may rest on noisy ground truth, which has direct implications for any safety claims built on those benchmarks.*

**5. Argus red-team probes target browser-using agents on prompt injection and credential theft** — The [Argus](https://github.com/gy15901580825/Argus) agentic red-teaming toolkit shipped several new browser probes this week: testing whether an agent overrides a visible invoice total when injected text tells it otherwise ([PR #286](https://github.com/gy15901580825/Argus/pull/286)), whether it follows an injected payee-redirect while paying an invoice ([PR #287](https://github.com/gy15901580825/Argus/pull/287)), and whether stored credentials from an agent's own vault leak to look-alike phishing pages ([PR #293](https://github.com/gy15901580825/Argus/pull/293)). *Why it matters: these probes operationalize some of the most realistic agentic-AI threat scenarios (prompt injection causing financial harm, credential exfiltration) rather than testing abstract jailbreak strings.*

## Notable GitHub Releases & Tools

- **[agent-airlock v0.10.35](https://github.com/sattyamjjain/agent-airlock/releases/tag/v0.10.35)** — Fixes `ShellCommandPolicy` to check *where* a shell command writes (redirection targets, `find`'s delete/write actions), closing a gap where an allowed command like `echo` could still be used to overwrite `/dev/sda` or `/etc/passwd`. *Why it matters: this closes a real privilege-escalation path in a tool specifically built to sandbox agent shell access.*

- **[evalproof 1.0.0–1.3.0](https://github.com/technobasant/evalproof/releases/tag/v1.0.0)** — A flurry of releases bringing a stable public API, `evalproof scan` (static repo analysis of model calls/agents/tools to find untested gaps), dataset importers for promptfoo/DeepEval/Ragas/Inspect/etc., and rubric-based LLM-judge grading. *Why it matters: lowers the barrier to adding systematic eval coverage to existing agentic codebases rather than bolting evals on as an afterthought.*

- **[NVIDIA-NeMo Guardrails — injection_detection bypass fix](https://github.com/NVIDIA-NeMo/Guardrails/pull/2559)** — Fixes occurrence-order bypasses in Python/Jinja/XSS injection-detection rules and adds re-checking of omitted output against all configured rules before allowing unsafe content through. *Why it matters: guardrail bypass bugs directly undermine the product's core safety promise for production LLM deployments.*

- **[promptfoo — prototype pollution and credential-logging fixes](https://github.com/promptfoo/promptfoo/pull/12133)** — Fixes sanitization that previously could drop an input's own `__proto__` field, plus a [separate fix](https://github.com/promptfoo/promptfoo/pull/12352) stopping raw `Authorization`/API-key headers from being written into HTTP provider warning logs. *Why it matters: these are the kind of supply-chain/secrets-hygiene bugs that matter once a red-teaming/eval tool is wired into CI with real credentials.*

- **[spectral-trust 0.5.0](https://github.com/vcnoel/spectral-trust/releases/tag/v0.5.0)** — Adds an `interventions` subpackage bringing TransformerLens-style patching, ablation, and steering to the graph-spectral interpretability domain, plus animated visualizations (0.4.2) for mechanistic traces. *Why it matters: extends a lighter-weight interpretability toolkit with intervention capabilities previously confined to TransformerLens-specific workflows.*

- **[Argus v1.14.0](https://github.com/gy15901580825/Argus/releases/tag/v1.14.0)** — Adds a probe for mid-session MCP tool-description changes that leak other customers' records, plus reworks four existing probes to score the attack itself rather than ordinary agent behavior. *Why it matters: mid-session tool-description mutation is an underexplored MCP attack vector that this release makes testable out of the box.*

- **[RedWidow v1.0.9](https://github.com/tomtimlt/RedWidow/releases/tag/v1.0.9)** — First public release of a VS Code extension letting AI agents drive pentest tooling (Kali/Exegol containers) with supervised, approval-gated execution modes. *Why it matters: packages human-in-the-loop controls directly into an AI-driven offensive security workflow, a pattern other agentic-tooling projects should emulate.*
